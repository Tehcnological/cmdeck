# Message pins

Pin a message to keep it one click away: a plan you agreed on, a command that worked, a decision you want to find again.

## Pin and unpin

- Hover a message (tap on touch screens) and click the pin in its actions. Click it again to unpin.
- Your messages and agent responses can both be pinned. A thread holds up to 50 pins.

## Find your pins

Open the thread's **Pinned messages** tab in the right panel: choose **Show pinned messages** in the command palette. Click a pin to jump to its message; older messages load on the way if needed. Each pin also has an unpin button.

Pins are stored on the server, so every browser and desktop app connected to it sees the same pins. The tab refreshes when you open it or come back to the window. The official T3 Code mobile app does not show pins.

## Good to know

- A pin keeps a short opening of the message so the list is readable. Anything that looks like a secret (an API key, a token) is masked in it.
- A message folded into its turn's work log jumps to the start of that turn.
- If a message is gone (for example after rewinding the thread), the jump says so and you can unpin it.
