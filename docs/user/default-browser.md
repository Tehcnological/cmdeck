# Use CMDeck as your default browser

On macOS, you can set the CMDeck desktop app as your default web browser so links from other apps and local HTML files open directly in CMDeck.

## Enable

Choose **CMDeck** in **System Settings → Desktop & Dock → Default web browser** (switch back there anytime).

## How links open

- If the active thread has its browser panel open, the link opens as a new tab there; otherwise CMDeck opens a new no-project thread with the browser panel maximized so you can ask an agent about the page right away.
- Pull request links for connected projects open in the PR view (when **Open pull requests in CMDeck** is enabled).
- [Prompt links](./prompt-links.md) to `app.t3.codes` open as a draft.
