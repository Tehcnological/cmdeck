## 1. Executive summary

- **CMDeck already owns most of the infrastructure these projects sell.** It has a journaled
  `effect/workflow` engine with durable waits and failed-step retry, FTS5 search on `node:sqlite`, a
  playwright-core browser with CDP screencast and human takeover, subscription-limit probes, a
  LiteLLM price map, scheduled tasks with signed webhooks, and second-model review (CL §4–§6, COV).
  No durable-execution, memory, browser, tracing or policy **framework** is worth adopting.
- **What competitors contribute is patterns.** The strongest per gap:
  - CMD-09 Docker sandbox: Agent of Empires' mount table plus Agent Orchestrator's label reaper and
    Nimbalyst's egress-off allowlist.
  - Memory (MEM-*): OpenClaw provenance stored outside content, Hermes frozen-at-session-start
    snapshot, Mem0 additive extraction, Graphiti supersession.
  - Agent-to-agent messaging (AGT-09): Podium's delivery brakes and human-ceiling addressing.
  - AUT-02 scripts: Sillage's exit-code check gate.
  - Autonomous runs: OpenHands' deterministic `StuckDetector`.
- **Only a few small, permissive TS dependencies are worth adding**: `@slack/bolt` and `grammy` for
  messaging (D13), `web-push` for PWA notifications (D8), and later, only if measured, `sqlite-vec`
  and `web-tree-sitter`.
- **CMD-10 Windows Sandbox has no reference** in any ADE, and Kiro Crew has no Windows sandbox at all.
  The only Windows lead is OpenShell's experimental Microsoft MXC branch (CL §7).
- **Telemetry is the norm, not the exception.** Five ADEs (Emdash, Agent Orchestrator, Podium,
  Nimbalyst, Frink) and nine libraries send telemetry by default or opt-out (§6). None may be used as a runtime dependency without forcing its kill switch, which
  conflicts with brief §10, so none is recommended.
- **License traps**: Screenpipe is source-available commercial; Alethe is AGPL-3.0; PandaCode adds a
  visible "fork of PandaCode" notice obligation; LiteLLM, Langfuse and Tabby mix MIT/Apache with
  commercial `enterprise`/`ee` directories; Agent Orchestrator pulls in an unlicensed private submodule.
- **New ideas** (not roadmap scope) are consolidated in [NEW_FEATURE_PROPOSALS.md](NEW_FEATURE_PROPOSALS.md).

## 5. Security warnings (beyond telemetry)

- **Emdash** remote installer pipes `curl https://releases.emdash.sh | sh` without passing the supported
  `--sha256` (CA). Pin installer hashes if the SSH-to-socket pattern is copied.
- **Agent of Empires** sandbox image has no `USER` (runs as root, **inferred**), installs ~12 CLIs via
  `curl | bash`, has no egress allowlist, and Apple Container loses read-only mounts.
- **Agent Orchestrator** daemon listens on loopback **unauthenticated**; mobile auth is a rotating bearer
  password with no E2EE.
- **Jean** headless `token_required` can be disabled, which is risky on public binds.
- **Hermes** memory write gate **fails open** if the gate module cannot load (`memory_tool.py:84-90`).
  CMDeck must fail closed.
- **Paseo** plugins run unsandboxed; **Frink** custom flow nodes run unsandboxed.
- **container-use** isolates only commands routed through its MCP tools; the harness's native tools still
  touch the host (**inferred**).
- **OpenChamber** routing classifier and goal auditor send prompt text to third-party endpoints unless
  set to off or custom.
- **Playwright MCP** `--allowed-origins` and agent-browser domain allowlists are explicitly **not**
  security boundaries; CMDeck docs must say the same.
- **Kiro Crew** (see KIRO_CREW_PORT_ANALYSIS.md §6): model-written Python run in the gateway, real
  Chrome profile by default, vault key beside ciphertext, no Windows sandbox, redaction off by default.
