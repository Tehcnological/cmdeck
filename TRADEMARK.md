icons for its branding.

## Where "T3" still appears

These references stay for compatibility or attribution, not as branding:

- **Compatibility identifiers.** The official T3 Code mobile apps and other T3 Code servers depend
  on them: the `t3` command (kept as an alias of `cmdeck`), `t3code://` links,
  `/.well-known/t3`, the orchestration protocol, RPC and schema names, pairing and auth formats,
  mDNS service names, and the internal `@t3tools/*` package names.
- **Text the AI agents read.** The MCP server name and agent instructions keep upstream's wording,
  because recorded replays and evals depend on it.
- **Plain-text attribution.** The README, LICENSE, and docs state that CMDeck is derived from
  T3 Code and explain how the two coexist.
- **Upstream sources kept for merging.** `apps/marketing` (T3 Code's website) and `infra/` (the
  T3 Connect relay) stay in the tree so upstream merges stay clean. CMDeck does not build, deploy,
  or publish them.
